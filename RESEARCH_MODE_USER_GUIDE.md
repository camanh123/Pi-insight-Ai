## Information Type Badges Explained

### 🟢 Official (Green)
**What it means:** This is a fact from official Pi sources
**Example:** "According to the official announcement: Pi moved to Mainnet on January 1, 2024"
**Trust Level:** High — directly from official sources

### 🔵 Analysis (Blue)
**What it means:** The AI interpreted official facts and connected them
**Example:** "AI Analysis: KYC and Mainnet work together because..."
**Trust Level:** Medium-High — based on official sources but requires interpretation
**Always includes:** Confidence Score showing how certain the AI is

### 🟠 Prediction (Amber)
**What it means:** The AI made a forward-looking guess based on patterns
**Example:** "AI Prediction (not fact): Pi could reach more countries in Q3"
**Trust Level:** Low — speculative, not from official sources
**Important:** Always labeled clearly as "Prediction, not fact"

```

├─ Very reliable information
└─ Safe to rely on
   [████████████████ GREEN BAR]

70-84% Confident
├─ Official sources mostly agree
├─ Some interpretation needed
└─ Generally reliable
   [██████████████ BLUE BAR]

60-69% Confident
├─ Limited official support
├─ Significant synthesis/interpretation
└─ Use with caution
   [███████████ AMBER BAR]

Below 60% Confident
├─ Weak official support
├─ Mostly speculation
└─ Use for exploration only
   [██████ RED BAR]
```

### How to Use Confidence Scores
- **High scores (85+):** Safe to share with others
- **Medium scores (70-84):** Good background info
- **Low scores (60-69):** Use for learning, not decisions
- **Very low (<60):** Treat as AI speculation

## Response Sections Explained

### KEY FINDINGS
The direct answer to your question in 1-2 sentences.
**Use this for:** Quick answer if you're in a hurry

### OFFICIAL EVIDENCE
2-5 specific facts from official Pi updates that support the answer.
Each includes: The update title, the source ID, and the actual fact.
**Use this for:** Verifying the answer is really from Pi
**You can:** Click the update ID to see the full official update

### FOR BEGINNERS
The same concept explained simply, without jargon.
Often includes everyday analogies (like the concert tickets example above).
**Use this for:** Understanding if the concept is new to you

### AI ANALYSIS
How the AI connects different official updates together.
**Includes:**
- Why these updates relate to each other
- What this means for Pioneers
- Patterns the AI noticed
- Confidence Score for this analysis

**Use this for:** Understanding deeper connections

### TECHNICAL DETAILS (When Applicable)
More advanced explanation with technical terms.
Only shown if the topic requires it.
**Use this for:** If you want to understand the "how" not just the "what"

### RELATED OFFICIAL UPDATES
2-3 other official updates that deepen your understanding.
**Why it's here:** Helps you explore related topics
**Use this for:** Learning progression — what to study next

### CONCLUSION
1-2 sentence summary of the answer.
Always includes a Confidence Score.
**Use this for:** The final takeaway

## Tips for Getting Better Answers

### 1. Ask Specific Questions
✅ Good: "What's the difference between KYC and KYB?"
❌ Vague: "Tell me about verification"

**Why:** Specific questions trigger more relevant multi-update synthesis.

### 2. Ask Follow-Up Questions
✅ Good: First "What is KYC?" → Then "Who reviews KYC applications?"
❌ Bad: Asking unrelated questions breaks the conversation flow

**Why:** The Advisor remembers context for better synthesis.

### 3. Pay Attention to Confidence Scores
✅ Trust high scores (85+) — Multiple official sources agree
❌ Don't rely on low scores (<60) — Mostly interpretation

**Why:** Confidence shows how certain the answer is.

### 4. Read FOR BEGINNERS First
✅ Start with "FOR BEGINNERS" section
❌ Jump straight to technical details

**Why:** Gets you oriented before deeper concepts.

### 5. Explore Related Updates
✅ After answering, check "RELATED OFFICIAL UPDATES"
❌ Ignore them and move to a new topic

**Why:** Learning progression deepens understanding.
